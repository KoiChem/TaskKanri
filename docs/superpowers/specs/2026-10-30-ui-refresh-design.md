# UI改善の確定仕様

目的：開始・管理操作を見つけやすくし、時数候補の大量表示を解消する。

1. 開始カードは画面内に中央配置。ログインとオフラインを縦に並べ、44px以上・12px間隔。同じカード内でログインフォームへ切替可能。前回オフラインの即時起動を保つ。
2. 「コマを数える授業」の候補ボタン表示は維持。候補元は一括入力が成功した授業時限の先頭語だけ。通常メモや朝昼放課後は除外。既存条件・自由追加は保持する。過去の出所を推定しない。
3. 一括入力表の土曜は淡い水色、日曜は淡い赤、平日の朝昼放課後は淡いグレー。入力欄の内部も塗る。曜日見出しと時限列を固定し、時限名を折り返さない。
4. 共通タスク／ToDo行の右へ「授業時数」「日付の一括設定」「設定」。通常ボタンとタブの意味を分離し、8px間隔と折返しを確保。データ入出力は同期設定に集約し「データを書き出す」「データを読み込む」。同期入口は状態に加えて「同期設定」と表示。

採用：既存レイアウト・集計・バックアップを活かす。入力時のみ候補表示へ変更する案はユーザー訂正により不採用。新しい時間割マスターは設けない。

実装判断：候補履歴は補助情報としてtimetableWordsに端末保存・ファイル入出力する。クラウドから予定を取得してもローカル候補を保持する。既存の厳密な共有契約とDBを変更する必要はない。候補の端末間自動共有は今回の要件外。
