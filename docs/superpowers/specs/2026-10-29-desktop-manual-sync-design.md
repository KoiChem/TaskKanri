# PC手動同期とタスクタブ

ユーザーは2026-10-29に以下の方針による仕様確定・実装・検証・公開を承認。

- PCは端末保存を維持しクラウドの送受信は手動。新しいタブで最初に通常アクセスした場合のみ、未送信変更がないときに一度取得する。同じタブの再アクセス、reload、強制reload、履歴移動、表示復帰、通信復帰では取得しない。判定できない場合も手動。
- 起動時の未送信変更を保持し自動送信しない。通信失敗も手動で再試行。認証維持・権限確認は同期とは別。明示的なログイン後は利用開始のため取得するが、未送信変更があれば自動取得しない。モバイルの自動同期は変更しない。
- 同期メニュー上部に「今すぐ同期」。Ctrl+Alt+S / Mac Cmd+Option+Sも同じ処理。確定済みの編集を端末保存してから実行、IME中・連打を抑止。結果と未送信状態を明示する。競合は既存のCAS保護と書き出し・再取得を維持。
- 共通タスク枠を「共通タスク」「ToDo一覧」のタブに変更。左下の一覧ボタンを撤去。既存年度の未完了抽出を再利用し、日付・時限へ移動、共通項目は共通編集へ。日付移動後もタブと一覧スクロールを維持。タブ間に間隔を確保し、本文は初期高さ300px・最小120pxとし、下辺のハンドルを上下にドラッグして調節できる。上下矢印キーでも20pxずつ調節できる。高さは両タブで共通にし、このブラウザのlocalStorageに保持する（日付移動・リロード後も復元）。枠内はスクロールし、高さの変更はクラウド同期対象に含めない。

## 検討案
完全手動と起動時取得例外を比較し後者を選択。さらにリロード等では取得しない条件を合意。ToDoボタン移動のみとタブ化を比較しタブ化を選択。データ形式の変更や自動マージは追加しない。

## 検証
起動条件、pending再読み込み、失敗・競合、入力中の手動同期とIME、タブ・ジャンプ・スクロール、モバイル既存動作を使い捨てブラウザfixtureで確認。単体全件とbuild、diff checkを通し、mainのPagesデプロイと公開資産を確認する。実アカウントデータは操作しない。
