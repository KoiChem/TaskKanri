# 共通・授業タスクとToDo二列表示
ユーザー承認済み（2026-11-13）。PCでは既存の共通タスク/ToDo一覧タブを維持し、各内容を同幅の左右二列にする。共通タスクの左は既存データ、右は独立した授業タスク。PCには左右の見出しを表示しない。各編集欄は独立スクロール。高さ変更は既存操作を維持。
モバイルは予定・共通・授業・未完。同期を上段右に移し、44px操作領域とボタン間隔を確保する。
ToDoは共通・授業・日別の未完了タスクを集約。左列を枠の高さまで埋め、続きは右。両列超過時は枠内で縦スクロールする。状態ボタンのみで未→途→済→急→未を即時保存し、本文は既存の元入力欄へ移動する。済はToDo表示中同じ位置に残し、共通タスクへ切り替えると除外する。
独立HTML項目としてlessonTaskDataを追加。旧データは共通維持・授業空欄に移行。バックアップ/復元/差分表示/同期/競合/下書きを対応し、旧クライアントの保存による欠落を防止する。既存未公開の変更は対象外。
比較: 一つのHTMLを見かけだけ二列化する案は独立保存を満たさないため採用せず、二つの独立HTMLを採用。ToDoの件数均等分割は左を埋める要求と異なるため高さ基準の分割を採用。
